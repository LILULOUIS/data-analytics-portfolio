# COVID Data Exploration — SQL

## What this shows
SQL exploration of COVID deaths and vaccinations data using joins, CTEs, temp tables, window functions, aggregate functions, views, and data-type conversion.
## Questions answered
- Death percentage by country and date
- Percentage of population infected
- Countries with the highest infection rate and death count
- Global totals, and rolling vaccinations as a percentage of population
## Data
CovidDeaths and CovidVaccinations tables. The large Excel source files are not copied here; get them from the source repository.
## Skills
SQL Server / T-SQL, joins, CTEs, window functions, temp tables, views.
