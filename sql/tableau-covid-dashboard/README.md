# Tableau COVID Dashboard — SQL Queries
Adapted from AlexTheAnalyst/PortfolioProjects (https://github.com/AlexTheAnalyst/PortfolioProjects).
## What this shows
The SQL queries behind a Tableau COVID dashboard: global totals, death counts by location, infection rates by population, and rolling vaccinations as a percentage of population.
## Data
CovidDeaths and CovidVaccinations tables. The large Excel source files are not copied here; get them from the source repository.
## Skills
SQL Server / T-SQL, Tableau-ready result sets, aggregation, CTEs, window functions.
