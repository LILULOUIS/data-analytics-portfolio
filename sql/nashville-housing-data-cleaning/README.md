# Nashville Housing Data Cleaning — SQL
Adapted from AlexTheAnalyst/PortfolioProjects (https://github.com/AlexTheAnalyst/PortfolioProjects).
## What this shows
End-to-end data cleaning in SQL: standardizing dates, filling missing property addresses with a self-join, splitting addresses into address / city / state, standardizing Yes/No values, removing duplicates with ROW_NUMBER, and dropping unused columns.
## Data
NashvilleHousing table. The Excel source file is not copied here; get it from the source repository.
## Skills
SQL Server / T-SQL, data cleaning, data quality, self-joins, string functions, CTEs, window functions.
## Why it matters for data management
This is the kind of cleaning and standardization work that makes downstream reporting and dashboards trustworthy.
